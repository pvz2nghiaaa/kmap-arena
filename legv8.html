CẨM NANG HỢP NGỮ LEGv8 (ARMv8 64-BIT)

⚡ 1. Quy Ước Tập Thanh Ghi 64-bit & Điều Cấm Kỵ

Tập thanh ghi LEGv8 theo giáo trình chuẩn máy tính Patterson & Hennessy:

Thanh ghi Tên gọi & Ý nghĩa Trách nhiệm bảo tồn
X0 – X7 Truyền tham số đầu vào cho hàm & Trả về kết quả (qua X0) Caller-saved (Người gọi tự lưu)
X9 – X15 Thanh ghi tạm thời cho các phép toán trung gian Caller-saved (Không bảo toàn qua hàm)
X16 – X17 IP0, IP1: Thanh ghi nháp nội bộ cho linker / gọi hàm Caller-saved
X18 Platform Register: Dành riêng cho nền tảng hệ điều hành Đặc biệt
X19 – X27 Lưu trữ biến cục bộ. BẮT BUỘC lưu vào Stack và khôi phục lại trước khi thoát hàm! Callee-saved (Hàm được gọi phải bảo tồn)
SP Stack Pointer: Con trỏ đỉnh ngăn xếp (chỉ dùng từ khóa SP, căn lề 16-byte) Callee-saved
LR (X30) Link Register: Lưu địa chỉ quay về khi gọi lệnh BL. Thoát hàm bằng BR LR Caller-saved (Cần lưu nếu là non-leaf)
XZR Zero Register: Luôn bằng hằng số 0, mọi lệnh ghi vào XZR đều bị hủy bỏ Hằng số 0
⛔ ĐIỀU CẤM KỴ: Hệ thống phần cứng NGHIÊM CẤM sử dụng các thanh ghi: X8, X28, X29, X31. Luôn dùng SP thay cho X28, và dùng XZR thay cho X31!

📦 2. Kiến Trúc Ngăn Xếp (Stack Frame) & Thủ Tục

Ngăn xếp phát triển từ địa chỉ cao xuống địa chỉ thấp. Kích thước cấp phát luôn là bội số của 16 bytes.

// 1. Thủ tục Lá (Leaf Procedure - Không gọi hàm con khác): leaf: ADD X9, X0, X1 // Tính toán trực tiếp SUB X0, X9, X2 // Trả kết quả qua X0 BR LR // Quay về ngay lập tức (không cần Stack) // 2. Thủ tục Non-Leaf / Đệ Quy (Có gọi hàm khác qua BL): func: SUBI SP, SP, #16 // Cấp phát 16 bytes trên ngăn xếp STUR X30, [SP, #8] // Lưu LR (địa chỉ quay về) STUR X0, [SP, #0] // Lưu tham số X0 // ... gọi hàm con bằng BL func_con ... LDUR X0, [SP, #0] // Khôi phục tham số LDUR X30, [SP, #8] // Khôi phục LR ADDI SP, SP, #16 // Giải phóng ngăn xếp BR LR // Quay về

📑 3. Bảng Tra Cứu Nhanh Tập Lệnh LEGv8

Lệnh Cú pháp mẫu Ý nghĩa hoạt động
ADD / SUBADD Rd, Rn, RmCộng / Trừ 2 thanh ghi: Rd = Rn ± Rm
ADDI / SUBIADDI Rd, Rn, #immCộng / Trừ với hằng số tức thời (bắt đầu bằng #)
SUBS / SUBISSUBS XZR, Rn, RmTrừ và cập nhật cờ N, Z, C, V (Dùng để so sánh Rn với Rm)
MULMUL Rd, Rn, RmNhân 2 thanh ghi: Rd = Rn × Rm
LSL / LSRLSL Rd, Rn, #3Dịch trái / phải bit (#3 tương đương nhân 8 tính byte offset mảng)
AND / ORR / EORAND Rd, Rn, RmPhép toán logic bit AND, OR, XOR
LDURLDUR Rt, [Rn, #offset]Nạp 64-bit từ ô nhớ: Rt = RAM[Rn + offset]
STURSTUR Rt, [Rn, #offset]Lưu 64-bit vào ô nhớ: RAM[Rn + offset] = Rt
BB LabelNhảy không điều kiện tới nhãn Label
